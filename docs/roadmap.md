# 商用版で追加すべき機能

優先度は「受注後すぐ」「運用開始まで」「拡大期」の3段階です。

## 受注後すぐ（本番運用の前提）

| 機能 | 内容 |
|---|---|
| 本番認証 | Supabase Auth 等による個別ログイン、多要素認証、パスワード再設定、招待フロー。デモ用のペルソナ切替・ワンクリックログインは無効化 |
| 実AI運用 | Anthropic API の本番キー管理、応答拒否時のフォールバック、タイムアウト・再試行の調整、プロンプト評価（回帰テスト用データセット） |
| 実情報源の選定 | 収集対象（公式発表、行政機関の公表、報道）の選定、利用規約・著作権の確認、取得頻度の設定、robots.txt の順守 |
| 定期収集 | スケジューラー（Cron／キュー）による自動収集と失敗時の再実行・通知 |
| 常設ホスティング | Vercel / Cloud Run 等 + Supabase（PITRバックアップ、監視、ログ基盤） |
| CSP の nonce 化・WAF | `unsafe-inline` の撤廃、Cloudflare WAF / Bot 対策 |
| 共有レート制限 | Redis（Upstash 等）による複数インスタンス対応 |

## 運用開始まで

| 機能 | 内容 |
|---|---|
| 通知チャネル | メール・Slack・Teams への承認依頼／続報／契約期限の通知 |
| 公開先連携 | 事務所既存サイト（WordPress 等）への配信、独自ドメイン、OGP画像の自動生成 |
| 承認ルールの設定 | 二重承認（作成者と承認者を分ける）、事務所ごとの承認者指定 |
| 広告表現ルールの管理画面 | 事務所ごとの禁止語・言い換え候補の追加、所属弁護士会の規程への対応 |
| リッチ編集 | 見出し・箇条書き・表、共同編集・コメント |
| 利用量課金 | AI利用量・記事数に応じた請求、上限到達前の通知 |
| アクセス解析 | 公開ページの閲覧数・相談フォームへの遷移数（個人を特定しない形で） |

## 拡大期（他業種展開を含む）

| 機能 | 内容 |
|---|---|
| 業種テンプレート | 事件カテゴリ・広告表現ルール・記事テンプレートを業種ごとに切替（士業、医療、金融など）。カテゴリと規則はデータ化済みのため拡張しやすい構造 |
| 多言語 | 英語等での記事生成・公開 |
| 事件の名寄せ高度化 | 埋め込みベクトルによる類似事件の統合、組織名辞書 |
| 監査レポート | 承認記録・出典追跡のエクスポート（PDF） |
| SSO / SCIM | 大規模事務所向けのディレクトリ連携 |
