# 既知の問題・制約

| # | 区分 | 内容 | 影響・回避策 |
|---|---|---|---|
| 1 | AI | 実AI（claude-opus-5-5）では記事生成に30秒〜1分かかり、1記事あたり約$0.09の費用が発生します。公開デモではアクセスコードを知っている人なら誰でも、事務所ごとの月間上限（400回／120回）まで実行できます。 | 必要に応じて Operations Center で上限を下げてください。APIキー未設定または `AI_FORCE_SIMULATION=true` の場合は「AIシミュレーション」で動作します。 |
| 2 | AI | 実AI利用時、安全分類による応答拒否（`refusal`）はエラーとして扱い、別モデルへの自動フォールバックは未実装です。 | 再試行で対応。商用版でフォールバックを追加予定。 |
| 3 | AI | シミュレーションのトークン数・概算コストは文字数からの推定値です（画面に「推定」と表示）。 | 実AIでは API の実測値を記録します。 |
| 4 | 収集 | デモの情報源は架空の公表文・報道（`/demo-sources/*`）です。実在RSSのコネクタは実装済みですが既定で無効・未検証です。 | 実在情報源の利用規約・著作権の確認が別途必要です。 |
| 5 | 公開 | 常設URL（Netlify 無料プラン + Neon 無料プラン）で公開中。無料枠（Netlify: 月間の関数実行時間・リクエスト数、Neon: 計算時間・容量）を超えると停止・低速化する可能性があります。Neon は無操作時に休止し、最初のアクセスが数秒遅くなることがあります。 | 利用が増える場合は有料プランへ移行してください。 |
| 6 | 公開 | 顧客メールアドレス単位のアクセス制限は未設定です（Netlify のチームログイン保護は、顧客が閲覧できるよう無効化しています）。 | デモアクセスコード（招待リンク）で入口を制限しています。 |
| 7 | デモ | ワンクリック登録で作成される体験用事務所は閲覧者ごとに分離されますが、事件情報（共通データ）と「共有のデモアカウント」は全員で共有です。情報収集を実行すると全員の事件一覧に反映されます。体験用事務所は30日で失効し、作成数には上限（既定200件、`SANDBOX_MAX`）があります。 | デモ全体の初期化は運営者のみ実行可能です（全員の体験用事務所も削除されます）。 |
| 8 | セキュリティ | レート制限はプロセス内メモリで実装しています。サーバーレス環境では関数インスタンスごとに数えるため、制限が緩くなります。 | 商用版では Redis（Upstash 等）の共有ストアに置き換えます。 |
| 9 | セキュリティ | CSP は Next.js のインライン実行のため `script-src 'unsafe-inline'` を許可しています。 | 商用版で nonce 方式に移行します。Lighthouse の Issues に記録される CSP 項目（記事エディタ）の原因は未特定です（ブラウザコンソールに違反は出ていません）。 |
| 10 | 性能 | Lighthouse の mobile プロファイル（CPU 4倍スロットリング）で Performance が 58〜75 です（desktop は 94〜99）。 | 詳細は `docs/test-report.md`。 |
| 11 | SEO | 架空データのため、公開記事ページは `noindex` に設定しています（Lighthouse SEO で減点）。 | 商用時に解除します。SEO設定は検索順位を保証するものではありません。 |
| 12 | 編集 | 本文の編集は段落単位のテキスト編集です（太字やリストなどの装飾は未対応）。同時編集はロックせず、後から保存した側に「他の画面で更新されています」と表示します。 | 商用版でリッチテキスト・共同編集を検討。 |
| 13 | 編集 | 文の分割は句点（。！？）基準です。句点を含まない長文や引用符内の句点では分割が意図とずれる場合があります。 | 出典の紐付けは Evidence Trace で修正できます。 |
| 14 | 依存関係 | `npm audit` で postcss（Next.js 同梱、ビルド時のCSS処理のみ）の注意喚起が残っています。自前のCSSのみを処理するため公開サイトでの悪用経路はありませんが、解消には Next.js 16 への更新が必要です。 | 商用版開発時に Next.js 16 へ更新します。 |
| 15 | 確認範囲 | ブラウザは Chromium のみ、端末はエミュレーションのみで確認しています。 | Safari・実機での確認は未実施です。 |
| 16 | データ | DBコンテナ `aiip-demo-db`（ポート5435）を新規に作成しました。作業前から存在していた `aiip-db`（ポート5434、前回作業の残りと思われるもの）には変更を加えていません。 | 不要であれば削除してください。 |
| 17 | 運用 | 公開環境のバックアップは関数の一時領域（/tmp）に作成されるため、実行記録は残りますがファイル自体は保持されません。 | 本番では Neon のポイントインタイムリカバリ（PITR）を利用します。 |
