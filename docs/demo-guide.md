# デモ操作ガイド

所要時間：基本の流れ 約5分、追加シナリオ 各1〜2分。
表示される企業・事件・法律事務所・人物はすべて架空です。AIは APIキー未設定の環境では「AIシミュレーション」と表示されます。

## はじめに（入力は不要です）

1. お送りした **招待リンク**（`…/invite/<コード>`）を開きます。アクセスコードがブラウザに記憶され、以後は入力不要になります。
2. 「**自分専用のデモ事務所で始める**」を押します。架空の法律事務所とアカウントが自動で作成され、そのままログインします（メールアドレス・パスワードの登録は不要）。他の閲覧者の操作の影響を受けません。
3. 画面右下に **デモガイド** が表示されます。ガイドは実際の操作が完了するたびに自動で次の手順へ進みます。
4. 次回以降は、ログイン画面またはトップページのボタンを押すだけで **前回の続きから再開** できます（このブラウザで30日間有効）。

2つの事務所の比較や、承認権限の違い（編集担当は承認できない等）を確認したい場合は、ログイン画面の「共有のデモアカウントで入る」から選べます。

## 基本の流れ（One-Click Demo Journey の7手順）

| # | 操作 | 確認できること |
|---|---|---|
| 1 | ガイドの「この画面へ移動」→ 東雲モビリティ（架空）の事件詳細 | 事件の発生日・公表日・影響人数、変更履歴、事務所ごとの確認状態 |
| 2 | 「出典」の公表文を開く | 取得・正規化された本文、公表日と取得日時 |
| 3 | 「AIで記事を生成」 | 処理ステップの表示 → エディタへ。事実文には出典番号が付きます |
| 4 | 本文や概要を編集 | 数秒で「自動保存済み」。編集した文は出典が外れ「根拠未確認」になります |
| 5 | 右ペイン「チェック」→「実行」 | 広告表現・出典の裏付け・必須項目・SEO・費用表示・相談フォームを判定 |
| 6 | 右ペイン「承認」→「承認申請」→「承認」 | 承認者・日時・対象バージョンが記録されます（編集担当では承認ボタンが出ません） |
| 7 | 「公開」→ 上部「プレビュー」 | Publication Simulator で Desktop / Tablet / Mobile の公開ページを確認 |

## 追加シナリオ

### A. Evidence Trace（出典追跡）
記事エディタの「出典確認」を開き、左の記事中の文をクリックすると、右の出典の該当箇所が強調表示されます。根拠のない文は警告され、「出典を紐付ける」で出典の文を選ぶと、本文に実在する場合のみ紐付けられます。

### B. 広告表現チェック
記事一覧から「青葉ライフ通販」の下書きを開くと、「必ず返金されます」「専門弁護士」「今すぐ相談しないと手遅れ」などが検出されています。修正するとチェックが通り、承認申請できるようになります。

### C. 情報収集と Smart Diff（続報による差分）
1. Incident Radar で「情報を収集する」を押します。取得→正規化→重複判定→分類→保存 の進行と、**取得に失敗した情報源（HTTP 503）**、**AIへの命令文を含む報道の検出**が表示されます。
2. 新しい事件（若葉ドラッグ・白鷺ホーム）が追加され、「ミナト精機」に**影響人数 12,400名（確定）**の続報が届きます。
3. 公開中だったミナト精機の記事は「要修正・再承認」になり、AIが更新案を作成します。「差分」で公開版と最新版を左右比較できます。
4. 公開サイトのミナト精機の記事は、承認されるまで **旧版（調査中）のまま** です。
5. もう一度「情報を収集する」を押すと、すべて重複として除外され、新規 0 件になります。
（さくら学習塾ネットの記事には、あらかじめ続報による差分が用意されています。）

### D. 事務所の切り替え（Tenant Switcher）
画面上部の事務所名をクリックし「柊 誠一」を選ぶと、柊総合法律事務所（架空）の記事・設定・公開サイトのデザインに切り替わります。青藍法律事務所の記事のURLを直接開いても表示されません（サーバー側の認可とRLSによる制御）。

### E. Operations Center（運営者）
切替で「運営管理者」を選びます。
- 「期限を14日後に」→ 契約期限の通知が運営者・事務所の双方に届きます
- 「上限到達を再現」→ その事務所の新規AI処理が拒否されます
- 「バックアップを実行」→ 実際にバックアップファイルを作成し、成功後にのみ「成功」と表示されます

### F. AIエラー時の動作
事務所設定の「AI API障害をシミュレーションする」をオンにして保存し、エディタでAI機能を実行すると、エラーメッセージと再試行ボタンが表示されます。AI Inspector に失敗記録が残ります。

### G. AI Processing Inspector と運用削減の試算
AI Inspector では各AI処理の入力要約・モデル・プロンプトのバージョン・処理時間・トークン数・概算コストを確認できます。「運用削減の試算」では記事数と作業時間から削減時間を試算します（入力値に基づく試算であり、実測値ではありません）。

## デモを最初からやり直す
画面右上のユーザーメニュー →「新しいデモ事務所で始め直す」。新しい事務所が作成され、最初から操作できます。
（デモ全体の初期化は、運営者アカウントのユーザーメニューからのみ実行できます。）
