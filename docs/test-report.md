## テスト中に発見し修正した不具合

| 発見元 | 内容 | 対応 |
|---|---|---|
| DB統合テスト | `aiip_app` が `aiip_public` を継承していたため、公開ロール用ポリシーがアプリにも適用され、未ログイン文脈で公開中の事件や他事務所の設定行が見えた | ロール付与を `WITH INHERIT FALSE` に変更し、テストを追加 |

| E2E | 「重要な変更ありのみ」チェックボックスが遷移完了まで反映されない | 楽観的に状態を更新 |
| E2E | スマホ/タブレットでログイン画面・Simulator が横にはみ出す | グリッドに基本列定義を追加 |
| E2E | 1280×720 でガイドパネルが承認ボタンに重なる | ガイドを既定でコンパクト表示に変更 |
| Lighthouse | 小さな文字のコントラスト不足（4.43:1 など） | 文字用の色をわずかに濃くし AA（4.5:1）を満たす |

### 未達項目と理由
- **Performance（mobile）58〜75**: CPU 4倍スロットリング下で、Reactのハイドレーションとスクリプト評価（TBT 0.4〜0.8秒）が支配的です。日本語Webフォントのウェイト削減（CSS 184KB削減）、トップページでの `motion` 不使用化で改善済み。さらに改善するには、ダッシュボードの一部をサーバーコンポーネント化し、フォントのサブセット化を行う必要があります。同一マシンで cloudflared を稼働中に計測しているため値は変動します（同条件の過去計測で 63〜85）。
- **SEO 83〜92**: 管理画面は意図的に `noindex`（`is-crawlable` 不合格）。公開記事ページも**架空データのため `noindex` にしています**（商用時は解除）。ダッシュボードは補足表示に12px未満の文字を使っており `font-size` で減点。
- **記事エディタ Best Practices 96**: Lighthouse の「Issues」パネルに CSP 関連の項目が1件記録されます。ブラウザのコンソールには CSP 違反は出ておらず、詳細は未特定です（既知の問題に記載）。
